# Regula-AI Future Roadmap

## Phase 1 — Strengthen the Core
- Separate compliance, market, and financial workflows clearly.
- Improve API connectivity, input validation, and error handling.
- Test the application with more product categories.

## Phase 2 — Improve Trust and Evidence
- Expand the curated BIS reference set with reviewed sources.
- Display source links, evidence status, and last-checked dates.
- Highlight uncertainty and when human review is required.

## Phase 3 — Improve Market and Financial Intelligence
- Add source-backed market indicators where reliable data is available.
- Make assumptions and calculation formulas visible.
- Support scenario comparison and exportable reports.

## Phase 4 — Pilot and Scale
- Gather feedback from MSMEs and compliance professionals.
- Improve multilingual accessibility and usability.
- Consider additional regulator/product coverage after validation.
- Add monitoring, security hardening, and deployment controls.

All items above are proposed future improvements, not claims that these capabilities are already implemented.
